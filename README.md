# Sober Configuration

This repository contains a Sober configuration profile used to customize client behavior and performance-related settings. The main file is `config.json`, which includes a large set of Roblox flags and tuning values that affect graphics, networking, physics, rendering, and overall client behavior.

## Overview

Sober is commonly used to apply advanced client-side configuration for Roblox experiences. This project stores a ready-to-use configuration file that can be placed in the Sober configuration directory or used as a reference for custom tuning.

The configuration includes many values such as:

- gamepad permissions
- Discord Rich Presence settings
- graphics and HiDPI options
- performance flags
- network and replication tunables
- physics and rendering experiment flags

## Repository Contents

- `config.json` — the main Sober configuration file

## Important Notes

This file is intended for advanced users. Editing these values without understanding their impact may cause:

- degraded game performance
- unexpected rendering behavior
- network instability
- compatibility problems with certain games or client environments

Use this repository carefully and only modify values that you fully understand.

## Clone This Repository

To clone this repository locally, run:

```bash
git clone https://github.com/sdqfrmnsyh/personal-config-sober.git
cd sober
```

If your repository uses a different remote URL, replace the example link with the actual project URL.

## Usage

1. Clone the repository.
2. Copy or move the `config.json` file into the appropriate Sober configuration location on your system.
3. Launch Sober and verify that the configured settings work correctly.
4. If needed, adjust the values according to your hardware and gameplay preferences.
